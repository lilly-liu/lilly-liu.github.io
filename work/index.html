+

The problem

Engineering teams needed repeatable workflows and useful AI adoption across the organization.

Built a long-running agent harness that generates pull requests from Jira tickets, with DynamoDB-backed memory and an internal MCP layer. Standardized backend builds with a self-service CLI.

Deployed to 5+ teams, with a 70% PR approval rate and approximately 20% higher PR throughput per team. Reduced new service setup from days to hours.
